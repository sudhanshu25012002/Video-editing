# Store icon (logo no. 3): vector rebuild

`helioslabs-store-logo.svg` is a clean vector rebuild of icon no. 3 from the logo sheet. Every dimension was measured
from the source image: the 56 px rounded square, the awning stripes and semicircle scallops, the shop shadow and
the underline. The mark is the official HeliosLabs brace path, fitted to the icon's position, scale and slant; the
three bars were measured separately. Gradients are fitted to the source pixels (mean colour error about 6/255).

`helioslabs-store-logo-white.svg` is the white version: a white base with the artwork in brand purple (#5A17E6),
keeping the original's light/lavender relationship.

PNG exports at 512 and 2048 px are included; the SVGs scale to any size.
`logo3-original*.png` / `logo3-white*.png` are the earlier pixel cut-outs (low resolution, kept for reference).
