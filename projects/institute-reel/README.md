# institute-reel

Coaching institute case-study reel at the original voiceover length (`vo/voiceover.wav`, 74s). Scenes turn like notebook pages (3D page turns), with ruled paper for the problem and clean app screens for the solution.

The music in `audio.html` is new: lo-fi / chill hip-hop at 85 BPM, with an FM electric piano, boom-bap drums, swung hats, sub bass and vinyl crackle. It is minor for the problem, keys-only for the owner's ask, and a brighter major groove from "So, we built". The sound effects are realistic and stereo-placed: page turns, pencil, keyboard, two-stage mouse clicks, marimba notifications, book thumps, stamp and hourglass sand.

```bash
node render.js beats 4 v && node render.js full 4 v && node audio.js   # then mix with vo/voiceover.wav, ducked
```
