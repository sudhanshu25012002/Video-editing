# offer-reel

₹999 e-commerce offer reel synced to `vo/voiceover.mp3`. Each scene slides up as a new card over the previous one (card deck). Score and sound effects are in `audio.html` / `audio.js`, each tied to a moment in the voiceover. The end card uses the full logo (purple rounded square).

```bash
node render.js beats 4 v && node render.js full 4 v && node audio.js   # then mix with the voiceover, ducked
```
