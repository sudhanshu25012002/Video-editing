# owner-reel

Story reel synced to `vo/voiceover.mp3` (subtitles and every scene timed to the voice). Score and sound effects are in `audio.html` / `audio.js`, and every effect is tied to a moment in the voiceover.

```bash
node render.js beats 4 v && node render.js full 4 v && node audio.js   # then mix with the voiceover, ducked (see projects/website-reel/README.md)
```
